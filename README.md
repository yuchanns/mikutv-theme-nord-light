# Nord Light for MikuTV

Arctic Snow Storm and Frost daytime palette inspired by Nord for MikuTV.

- **Plugin ID**: `nord-light`
- **Kind**: `theme` (`light` appearance, daytime pair for **Nord**)
- **Version**: `1.0.0`
- **License**: Apache-2.0

## Installation

1. Open **MikuTV** on Apple TV.
2. Go to **设置 → 外观与动态 → 白天主题 → 发现更多主题** (or **设置 → 插件管理 → 发现插件**).
3. Select **Nord Light** (`yuchanns/mikutv-theme-nord-light`) and install.
